# ADR 0003: 程序化音频生成

## 状态

已接受

## 背景

项目需要两种音频：
1. **游戏模式** - 捕捉成功的反馈音效
2. **动画模式** - 背景音乐 + 生物爬行音效 + 停顿音效

需要决定音频的实现方式：使用预录制音频文件 vs 程序化生成。

## 决策

使用 **Web Audio API 程序化生成** 所有音效，不引入外部音频文件。

## 考虑过的替代方案

### 替代方案1: 使用预录制音频文件
提取原视频音频或录制音效文件（MP3/WAV），通过 `<audio>` 元素或 AudioBuffer 播放。

**拒绝原因**：
- 增加文件体积（每个音效10-50KB）
- 需要处理音频格式兼容性
- 原视频音频存在版权风险
- 需要额外的素材管理流程

### 替代方案2: 使用 Web Audio API 生成 + 预录制背景音乐
音效程序化生成，但背景音乐使用预录制的循环音频。

**拒绝原因**：
- 背景音乐文件体积大（1-3MB）
- 增加加载时间
- 程序化生成可以实现足够柔和的背景旋律

## 后果

### 正面
- 零外部依赖，单文件即可运行
- 无版权风险
- 音效参数可动态调整（如连击时音调升高）
- 文件体积极小

### 负面
- 音质不如预录制音频丰富
- 背景音乐较简单（单音旋律）
- 需要更多代码实现音频逻辑

## 实现细节

### 音效类型

| 音效 | 实现方式 | 触发条件 |
|------|---------|---------|
| 捕捉音效 | Oscillator + Gain Envelope | 游戏模式点击生物 |
| 背景音乐 | 循环 sine 波旋律 | 动画模式启动 |
| 爬行音效 | BufferSource + 白噪音 + Lowpass Filter | 生物移动时持续 |
| 停顿音效 | Oscillator 降调 | 生物停止移动 |

### 音量层级

```
Master Gain (50%)
├── BGM Gain (15%)
└── SFX Gain (30%)
    ├── Catch Sound
    ├── Crawl Sound
    └── Pause Sound
```
