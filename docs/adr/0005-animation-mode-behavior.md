# ADR 0005: 动画模式生物行为设计

## 状态

已接受

## 背景

动画模式需要模拟原视频中生物的自然移动行为。通过分析视频帧，观察到生物具有以下特征：
- 从屏幕边缘进入
- 沿边缘爬行或穿越屏幕
- 偶尔停顿
- 尾巴持续摆动
- 从屏幕边缘离开

## 决策

实现 **四状态生物行为状态机**：

```
entering → moving → pausing → exiting
              ↑___________|
```

### 状态定义

| 状态 | 行为 | 持续时间 |
|------|------|---------|
| **entering** | 从屏幕外进入，向目标点移动 | 直到到达目标点或超时 |
| **moving** | 根据移动模式移动 | 1-5秒随机 |
| **pausing** | 减速停止，停留 | 1-3秒随机 |
| **exiting** | 加速向屏幕外移动 | 直到离开屏幕 |

### 移动模式

| 模式 | 描述 | 概率 |
|------|------|------|
| **漫游** (wander) | 随机方向移动，带正弦扰动 | 33% |
| **边缘爬行** (edge-crawl) | 沿屏幕边缘移动 | 33% |
| **穿越屏幕** (cross-screen) | 从一侧向对侧移动 | 33% |

### 生物属性规则

| 属性 | 规则 |
|------|------|
| 大小 | 直径20-40像素随机 |
| 速度 | 与大小成反比，大=慢，小=快 |
| 停留时间 | 总生命周期5-15秒随机 |
| 生成间隔 | 旧生物离开后延迟1秒 |

## 考虑过的替代方案

### 替代方案1: 完全随机移动
生物在屏幕上完全随机移动，无状态机。

**拒绝原因**：
- 缺乏自然感，不像真实生物
- 无法模拟停顿行为
- 生物可能聚集在屏幕中央

### 替代方案2: 预定义路径
使用贝塞尔曲线预定义移动路径。

**拒绝原因**：
- 路径重复，容易预测
- 需要大量路径数据
- 不同屏幕尺寸适配困难

### 替代方案3: 基于视频追踪
使用计算机视觉追踪原视频中生物的移动轨迹。

**拒绝原因**：
- 实现复杂度高
- 原视频生物移动简单，不值得
- 需要额外依赖（OpenCV等）

## 后果

### 正面
- 行为自然，模拟真实生物
- 状态机清晰，易于调试和扩展
- 参数可调，便于后续迭代

### 负面
- 状态机逻辑较复杂
- 需要仔细调整参数以达到最佳效果

## 待迭代参数

以下参数将在实际测试后调整：

| 参数 | 当前值 | 调整依据 |
|------|--------|---------|
| 停留时间 | 5-15秒 | 观察猫咪注意力持续时间 |
| 移动速度 | 1.5-3.5像素/帧 | 观察猫咪是否能跟上 |
| 停顿频率 | 每1-5秒停顿一次 | 观察猫咪是否对停顿有反应 |
| 生成间隔 | 1秒 | 观察猫咪是否需要更长的间隔 |
