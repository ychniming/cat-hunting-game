# ADR 0007: Verlet 积分尾巴物理

## 状态

已接受

## 上下文

生物尾巴使用位置历史方法（`tailSegments.unshift({x, y})`）记录身体轨迹，渲染时用均匀线宽直线段绘制。与参考动画帧对比发现：

1. 尾巴无锥形渐变，视觉上像等宽棍子
2. 直线段连接产生折线感，不够平滑
3. 正弦摆动机械感强，缺乏物理惯性
4. 位置历史方法无物理模拟，尾巴运动不自然
5. 段数过少（8/12），细节不足

## 决策

采用 **Verlet 积分链** 替代位置历史方法，配合 **锥形渐变渲染** 和 **Bézier 曲线平滑**。

### Verlet 积分链

- 每个节点存储当前位置和上一帧位置，通过位移差隐式计算速度
- 距离约束保持链段长度，模拟刚性连接
- 锚点跟随生物身体，其余节点自然延迟
- 可配置重力、刚度、阻尼参数

### 锥形渐变渲染

- 逐段绘制，线宽从根部 `radius * 0.6` 线性递减到尖端 `1px`
- 使用 `quadraticCurveTo` 在中间段实现平滑曲线连接
- 首段和末段使用 `lineTo` 和 `quadraticCurveTo` 特殊处理

### 状态感知物理

- 暂停状态：增大重力（×2）、降低刚度（×0.5），尾巴自然下垂
- 退出状态：减小重力（×0.5）、增大刚度（×1.2），尾巴紧随身体
- 默认状态：使用配置默认值

## 替代方案

1. **逆运动学 (IK) 链** — 计算复杂度高，需目标角度，适合精确控制但过度设计
2. **质量-弹簧模型** — 需要显式速度和加速度，参数调优复杂
3. **纯 Bézier 曲线** — 无物理模拟，仅视觉平滑

## 后果

### 正面

- 尾巴运动自然，有惯性和延迟效果
- 锥形渐变视觉接近参考动画帧
- Bézier 曲线消除折线感
- 状态感知使尾巴行为与生物状态一致
- 可配置参数便于调优

### 负面

- Verlet 链每帧需约束迭代（3次），增加 CPU 开销
- 逐段绘制增加 draw call 数量（16-20 次 stroke）
- 段数增加（8→16, 12→20）增加计算量

### 缓解

- 约束迭代次数可配置，默认 3 次平衡精度与性能
- getSegments() 使用帧内缓存减少 GC 压力
- 单生物尾巴渲染 < 0.5ms，在 16.67ms 帧预算内
